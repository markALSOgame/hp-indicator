# HP Indicator (Minecraft 1.16.5, Forge)

Клиентский мод, который показывает полоску сердечек и точное количество HP над головой каждого игрока.

## Возможности
- Реальное HP игрока над его головой в реальном времени (сердечки + число).
- Работает даже на игроках с невидимостью.
- Сердечки берутся из `textures/gui/icons.png` активного ресурспака — картинка всегда совпадает с текстурпаком.
- Меню настроек открывается клавишей **Home**:
  - слайдер **Size** — размер индикатора (0.5–3.0);
  - слайдер **Height Above Head** — высота над головой;
  - кнопка включения/выключения числа HP.
- Настройки сохраняются в `config/hpindicator-client.json`.
- Полностью клиентский мод: работает на любых серверах, ничего не отправляет.

## Сборка

Проект уже собран: `build/libs/hpindicator-1.0.0.jar` — его можно сразу кидать в `mods`.

Для пересборки (gradle wrapper 7.3.3 уже в проекте, нужен любой JDK 8+):
```
gradlew.bat build
```

### Запуск в среде разработки
```
gradlew.bat runClient
```

## Установка в игру
1. Minecraft 1.16.5 + Forge 36.2.x.
2. Положи jar в папку `mods`.
3. OptiFine совместим: ставится рядом (в `mods` или через установщик) без конфликтов.

## Замечания по коду
- Мэппинги: официальные Mojang (`mappings channel: 'official', version: '1.16.5'`) — как в актуальном MDK 1.16.5.
- Рендер: `RenderPlayerEvent.Pre` срабатывает и для невидимых игроков, поэтому их HP видно.
- Если сервер скрывает игроков (трекинг), мод физически не может знать их HP — это ограничение протокола.
