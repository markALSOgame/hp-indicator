# HollyWorld HP Indicator — Мод показывающий HP над головами игроков (1.16.5, Forge)

## Скачать готовый мод

Если вам просто нужен мод для игры — скачайте `hpindicator.jar` из корня репозитория и положите в папку `mods`.

- Minecraft 1.16.5
- Forge 36.2.x
- OptiFine совместим (ставить рядом в `mods`)
- Совместим с текстурпаками (сердечки берутся из `icons.png` активного пака)

## Сборка из исходников

Если хотите изменить мод под себя — клонируйте репозиторий и соберите:

```
git clone https://github.com/markALSOgame/hp-indicator.git
cd hp-indicator
gradlew.bat build
```

Готовый мод будет в `build/reobfJar/output.jar`.

Требуется JDK 8 или выше.

## Управление

| Клавиша | Действие |
|---------|----------|
| Home | Открыть меню настроек |

### Настройки (меню Home)
- **Size** — размер индикатора (0.5–3.0)
- **Height Above Head** — высота над головой
- **Show HP Number** — включить/выключить числовое значение HP
